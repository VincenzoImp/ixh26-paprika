⑥ Revoke this device key

For a key that was stolen or copied: the key signs its own revocation and the device is flagged; no vote, no money. Anyone holding the key can revoke it, including a thief. The owner then registers a new key.

③ Commit

UMA will be asked: "Is this photo not a genuine capture by key K?" Voters say yes only if the evidence is public and checkable (UMIP-170): the burden of proof is on the accuser.

Reveal

Paprika opens the case at UMA with the accuser's bond and, in the same transaction, contests it with the photographer's deposit. Both stakes (2B) go to UMA, so every accusation is decided by a vote, never by silence.
